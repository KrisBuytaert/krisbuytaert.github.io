Osoday 2027

November 4, 2026 · O11y Cfgmgmtcamp Fosdem

Back in 2024 I was asked to give a talk for the back then online only Open Source Observability Day. While I`m not a big fan of online only events, there really was a gap that needed to be filled. Sure, we have OSMC, there used to be Monitorama which happened iirc 2x in Europe, and there is the (close to impossible to attend) o11yday before Kubecon. But there is no event where the Open Source observabilty community meets. While chatting with Peter Zaitsev about Coroot, I already hinted that maybe we could do an in person OSoday in Ghent as a Fringe event to CfgMgmtCamp. It would be an ideal fit as a number of people with this interest would already be around for Fosdem or CfgMgmtCamp so it would be only one trip for multiple events .

So now I`m really happy to announce that we are making this happen.

Open Source Observability day 2027 will happen in person in Ghent on Wednesday February 3rd 2027.
You can expect a variety of O11y topics, Different tools will be present to tell you what they have been working on , but we’ll also look at the consumers of the tools and how they improved their ecosystem by using some of these tools.

So if you have an interesting tool / story, don’t hesitate to submit a proposal to our CFP.

Obviously just visiting is also an option .. Our registration is open , the event is free but we’d love to know how many of you we can expect.

And if there is a talk that doesn’t match your interest at a certain time slot, there are still more community events happening in the same building that day , check out the CfgMgmtCamp Fringe :)
